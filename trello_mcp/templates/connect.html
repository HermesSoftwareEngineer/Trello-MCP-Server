Conectar conta do Trello

Gere sua API Key e seu Token em trello.com/app-key. Suas credenciais ficam criptografadas no servidor e são usadas apenas para chamar a API do Trello em seu nome.

Como funciona

  1. Você cola sua API Key e Token do Trello acima.
  2. O servidor valida as credenciais direto no Trello — isso prova que a conta é sua.
  3. Você recebe um connector token para configurar no Claude.
  4. Cada chamada ao MCP usa esse token para descobrir de quem são as credenciais.

Perdeu o connector token? Conecte de novo com as mesmas credenciais do Trello: um token novo é gerado e o anterior é revogado.

Desconectar conta e apagar credenciais

Informe as credenciais do Trello da conta que deseja remover. Tudo que está salvo no servidor para ela será apagado e o connector token deixará de funcionar.
